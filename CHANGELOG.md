# Changelog

All notable changes to the Liqo website (`liqo-landing`) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive open-source documentation suite under [`docs/`](./docs/README.md).
- Company documentation: `VISION.md`, `PRODUCT.md`, `SCF.md`, `BRAND.md`, `PRESS.md`, `OPEN_SOURCE.md`.
- Repository health files: `LICENSE` (MIT), `SECURITY.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SUPPORTED_VERSIONS.md`.
- GitHub community health: issue templates, pull request template, issue chooser config.
- Redesigned `README.md` positioning Liqo as Global Payments Infrastructure for Modern Businesses.
- Mermaid architecture, payment, orchestration, and settlement diagrams.

### Notes
- Website functionality (landing page, waitlist, SEO) is unchanged by this documentation effort.

## [0.1.0] — Initial

### Added
- Marketing landing page with animated hero (three.js / react-three-fiber).
- Sections: features, how-it-works, use cases, developer experience, financial visibility, call-to-action.
- Waitlist page with validated form and submission API route.
- SEO foundation: metadata, JSON-LD, sitemap, robots, manifest, OG image.
- PWA icons and brand assets.
